## What we use

The set of positive integers having an iterate strictly below their starting value has natural density one, stated for the shortcut map `C(2n) = n`, `C(2n+1) = 3n+2`. Legacy use: calibration benchmark only, for Phase 6 audit L1 (S.1, P6-001) and explicit-Tao L2–L3, which prove their own explicit finite-horizon statements. Strict stopping exceptions are not the nonabsorbing basin.
