# Sources

External works this repository relies on: papers, published computations and outside Lean libraries. Each one is a node of kind `source` ([`conventions/SCHEMA.md`](../conventions/SCHEMA.md)), named `<first-author>-<year>-<topic>`.

A result that uses a source lists it under `assumes`. [`MAP.md`](../MAP.md) then shows the result as resting on it. A source is `cited` when taken as published, and `replayed` when it was rebuilt or re-run here.
