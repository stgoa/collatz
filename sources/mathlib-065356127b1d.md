[`lean-toolchain`](../lean/lean-toolchain).

## What we use

The integer, natural-number, parity, divisibility and polynomial
arithmetic libraries and their proof tactics. Result nodes name
the declarations they use or establish and provide a statement
match and axiom receipts. This library input is separate from
any external theorem about Collatz cycles or logarithmic gaps.

## How it is checked

The cached checkout's Git revision and origin match the pin and
official repository above. New importing modules are compiled
with the pinned toolchain and their declarations' axioms are
printed and audited. The precompiled Mathlib dependencies are
reused; the whole library has not been rebuilt from source in
this session. This source is therefore `cited`, not `replayed`.
See the [Lean build conventions](../lean/README.md) for the
standard-axiom and receipt requirements.
