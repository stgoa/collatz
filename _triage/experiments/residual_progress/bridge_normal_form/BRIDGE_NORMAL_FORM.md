# A complete normal form for the elementary sibling bridges

**Status: written proof, with bounded executable checks.** The result classifies
exactly the equivalence generated by one-step sibling identities and the R23
halving identities. It also gives the exact induced Syracuse map and all its
inverse branches. Termination of that induced map remains equivalent to the
unproved Collatz assertion. No novelty claim is made.

Use positive odd integers, the odd-only Syracuse map S, and S(1)=1 for algebra.
Measures and current rows at1 are killed. For a finite integer current J,
`div J=(I-P)J`. The [R23 note](../residual_return/SHRINKING_COALESCENCE.md)
supplies the halving identity used below; its elementary proof is recalled.
The independent side-lane feed is not a premise of these results.

## 1. Exactly two sibling rays in every elementary component

Write

```
F(x)=4x+1,
F^k(x)=(4^k(3x+1)-1)/3.
```

For odd positive x, S(F(x))=S(x). These rays contain every one-step sibling:
if S(x)=S(y), then `3x+1=2^a z` and `3y+1=2^b z` for the same odd z.
Modulo3, a and b have the same parity. Thus one of x,y is F^k of the other.
This includes the algebraic convention S(1)=1.

Call `x=2^a t-1`, a>=2 and t odd, **selected** when `t=3^a mod4`.
R23 proves

```
S^a(x)=S^a((x-1)/2).                                    (1)
```

Define the set of canonical minima

```
B = {q>0 odd: q=1 mod8}
    union {q=2^a t-1: a>=2, t odd, t=-3^a mod4}.          (2)
```

The elementary bridge graph has the undirected edges

```
x -- F(x)                       for every positive odd x,
x -- (x-1)/2                    for every selected x.
```

**Complete component theorem.** Its connected components are exactly

```
C_q = {F^k(q), F^k(2q+1): k>=0},       q in B.           (3)
```

Each component has the unique least member q. The graph consists of two
disjoint F-rays joined at their bases q and2q+1.

**Proof.** The inverse F step is available precisely at x=5 mod8 and sends
x to the smaller positive odd integer `(x-1)/4`. Iterating it terminates at
the unique F-root, which is1 mod8 or3 mod4. Equivalently its number of steps
is `floor((v_2(3x+1)-1)/2)`.

If a selected F-root is `p=2^a t-1`, its partner q is
`2^(a-1)t-1`. When a>=3, q is complementary because
`t=3^a=-3^(a-1) mod4`. When a=2, t=1 mod4 and q=1 mod8.
Thus q belongs to B and is itself an F-root.

Conversely, if q=1 mod8, then2q+1 has a=2 and selected t=1 mod4.
If q is complementary with parameters a,t, then2q+1 has parameters a+1,t
and is selected. These give the unique selected partner2q+1 of every q in B.
No selected root is in B, and selected roots have no further halving
partner on their other side. Every halving edge therefore pairs exactly
these two F-roots. This proves (3), including all possible inverse rewrites.

**Consequence for R23's unresolved roots.** Every remaining R23 seed belongs
to B. No finite sequence of the elementary identities, used in either
direction and through arbitrarily large intermediates, connects it to a
smaller integer. This is a limitation of the stated identity graph. It does
not prohibit new bridges, additional Syracuse arrows, or inverse lifting
of a relation through previously unused arrows.

## 2. Terminating normalization and an exact current

Let nu(x) be the minimum in (3). It is calculated by:

1. apply `(x-1)/4` while x=5 mod8;
2. if the resulting F-root is selected, apply `(x-1)/2` once.

The second step can never be repeated: its result lies in B. Both operations
strictly decrease. There are at most `floor(log_4 x)` inverse F steps and one
halving step. The map nu is idempotent, and nu(x)=nu(y) is equivalent to
membership in the same complete elementary component.

This algorithm provides an exact finite integer current with

```
div J_x = delta_x-delta_nu(x).                            (4)
```

To see this, let r be the F-root of x. If x differs from r, the current
`delta_x-delta_r` has divergence `delta_x-delta_r`, because their successors
coincide. If r is selected, append

```
D_r = sum_(j=0)^(a-1) delta_(S^j r)
      -sum_(j=0)^(a-1) delta_(S^j ((r-1)/2)).             (5)
```

Equation (1) makes (5) telescope to the required difference. Its prefixes
have the explicit finite length a; this is not a search for absorption.
All coincident rows retain their signed multiplicities. Killing delta1 and
row1 handles r=3 and its partner1 correctly.

For completeness, (1) follows from the first a-1 valuation1 steps of r and
the first a-2 of its partner. With z=3^(a-1)t, selection gives z=3 mod4;
their next states are2z-1 and(z-1)/2, related by F. Their successors coincide.

The implementation's `bridge(x)` returns the full current and these prefixes.
A supplied exact current for the smaller seed can be added to (4). Such
conditional reuse is legitimate for every individual seed. No finite current
can literally contain all the infinitely many members of a component at once.

## 3. Syracuse descends exactly to these components

The quotient is dynamically consistent:

```
nu(S(x)) = nu(S(nu(x)))              for every positive odd x.  (6)
T(q) = nu(S(q)),                     q in B.
T^n(nu(x)) = nu(S^n(x)),             n>=0.                      (7)
```

**Proof.** F-related states have equal successors. It remains to compare the
two bases q and p=2q+1 in (3).

If q=1 mod8, then

```
S(q)=(3q+1)/4,
S(p)=3q+2=F(S(q)).
```

This also holds at q=1 under the convention S(1)=1.
If q is complementary, then S(q)=(3q+1)/2 is again canonical. For a>=3 its
parameters are a-1 and3t, which satisfy the complementary congruence; for
a=2 it is1 mod8. Moreover

```
S(p)=3q+2=2S(q)+1,
```

so its successor is exactly the selected partner of S(q). This proves (6).
Iteration proves (7).

Consequently the induced map has the simple branch description

```
q complementary3 mod4: T(q)=(3q+1)/2 > q;
q=1 mod8, q>1:         T(q)<= (3q+1)/4 < q;
q=1:                   T(q)=1.                           (8)
```

Its arrow has an exact finite current: take the current row at q and append
the normalization bridge of S(q). Thus quotient transport has an explicit
lift retaining all signed rows.

Every member of C_1 reaches1 within two actual Syracuse steps: S(F^k(1))=1,
and S(F^k(3))=5 when starting from that ray. Therefore (7) gives

```
T^n(nu(x))=1  implies  S^(n+2)(x)=1,
S^n(x)=1      implies  T^n(nu(x))=1.                       (9)
```

Termination of T on all canonical minima is equivalent to ordinary Collatz
convergence. Formula (6) supplies closure of the state space, not a decreasing
global parameter. Members of C_1 do not all have the same hitting time; no
such claim is made.

## 4. All inverse branches, and why greedy inverse minimization fails

For a canonical y, every canonical predecessor q with T(q)=y is one of:

- the point `(2y-1)/3`, if y=2 mod3;
- a point `(4F^k(b)-1)/3`, where b is y or2y+1 and
  `k=1-b mod3`, k>=0.

**Proof.** A complementary predecessor has T(q)=S(q)=(3q+1)/2, giving the
first point. For every canonical y=2 mod3 this point is complementary:
when y=1 mod8 it is11 mod16, and when y is complementary its valuation1
predecessor has the complementary parameters one level earlier.

Otherwise a predecessor must be1 mod8. Its ordinary successor
`w=(3q+1)/4` belongs to C_y, so w=F^k(b). Integrality of q is exactly
w=1 mod3. Since F(w)=w+1 mod3, this is the stated congruence on k.
Conversely every listed point is1 mod8 and maps to y. The two families are
disjoint, and neither contains the complementary predecessor.

Increasing k by3 changes the predecessor by `q -> 64q+49`. Thus the entire
inverse set has the following finite description:

| y modulo3 | optional point | first point of each ray `q ->64q+49` |
|---|---|---|
|0|none|`(8y+3)/3`, `(16y+3)/3`|
|1|none|`(4y-1)/3`, `(32y+19)/3`|
|2|`(2y-1)/3`|`(64y+19)/3`, `(128y+83)/3`|

In particular the least predecessor is

```
L(y)=(8y+3)/3,   y=0 mod3;
L(y)=(4y-1)/3,   y=1 mod3;
L(y)=(2y-1)/3,   y=2 mod3.                               (10)
```

Although L gives the exact one-step minimum, iterating L need not give the
minimum at a greater inverse depth. There is a full parametric counterexample:

```
y=57+72j,       j>=0,
L(L(y))=409+512j,
min{q in B: T^2(q)=y}=203+256j.                          (11)
```

Indeed y=1 mod8 and y=3 mod9. Its two first inverse points are
`p_0=153+192j` and `p_1=305+384j`. The former is the smaller but is0 mod3;
the latter is2 mod3. Applying (10) gives respectively409+512j and203+256j.
All other first inverse points are at least64p_0+49. For every inverse point
z, (8) implies `L(z)>=(2z-1)/3`, so none of these later branches can beat
203+256j. This proves the stated minimum, rather than merely exhibiting a
smaller competitor.

The constructor `least_two_step_predecessor` is finite without a guessed
search cap. The greedy value B is an available upper bound. Any better q has
`T(q)<=(3B+1)/2`, so the exact inverse-ray enumeration up to that height is
exhaustive. This supplies a controlled inverse operation, but says nothing
about termination when the required inverse depth is allowed to grow.

## 5. Exact binary counting, with a uniform error bound

The canonical set has the disjoint binary description

```
q=1 mod8;
q=b_a mod2^(a+2), a>=2,
b_a=(3 if a even else1)*2^a-1.                            (12)
```

Let K_(m,r)(Y) count canonical q with1<=q<=Y and q=r modm, for any positive
odd modulus m. For Y>=1 put A=floor(log2(Y+1)). Combining each class in (12)
with q=r modm gives its exact CRT residue. Only a<=A can occur. Explicitly,
for a class b modp (p a power of2), put

```
rho = b+p*((r-b)*p^(-1) modm) mod(pm),
C(Y;rho,pm)=max(0, floor((Y-rho)/(pm))+1).
```

All rho here are positive odd residues. Then

```
K_(m,r)(Y)=C(Y;rho_0,8m)
           +sum_(a=2)^A C(Y;rho_a,2^(a+2)m),
abs(K_(m,r)(Y)-Y/(4m)) <= A+1/2.                         (13)
```

The error bound is uniform in the odd modulus and residue. Each of the A
progression counts differs from its length divided by its period by at most1.
Their density sum is `1/(4m)-1/(m*2^(A+2))`; the omitted term has magnitude
less than1/(2m). This proves (13), including A=1.

The two component strata have exact affine coordinates

```
x=4^k q+(4^k-1)/3,              q in B;
x=2*4^k q+(4^(k+1)-1)/3,        q in B.                   (14)
```

For each fixed k, the corresponding proportions among odd integers, or
within any fixed odd-modulus progression of odd integers, are respectively

```
(1/2)*4^(-k),       (1/4)*4^(-k).                        (15)
```

This follows directly by applying (13) to the affine ranges in (14).
The exact APIs `canonical_count` and `stratum_count` implement these CRT
formulas, not extrapolated proportions. The tail of F-depth at least K is
itself one binary progression, since it is precisely x=F^K(u) for odd u.
Its relative odd density is4^(-K). Thus the infinite stratification has an
explicit tail; (15) alone is not a license to assume probabilistic
independence along a deterministic orbit.

## 6. Remaining canonical seeds still have arbitrarily long ascents

For every odd a>=3, let x=2^a-1. It belongs to B. For0<=j<=a-1,

```
T^j(x)=3^j*2^(a-j)-1.                                   (16)
```

For j<a-1 these are complementary3 mod4 states and each step increases;
the last state is1 mod8. The peak is2*3^(a-1)-1, whose ratio to x tends to
infinity. Thus no fixed number of quotient steps guarantees descent, and no
uniform linear bound on the heights preceding its first decreasing branch
is possible for this map.

These are actual remaining R23 roots on the induction rays. For odd a>=13,
take `N=12*2^(a-4)`. Then b=a-4>=9, x=7 mod12, and
`9N/8<x<3N/2`; its full R'_N coefficient is1. All a-1 increasing quotient
steps are identical to its actual Syracuse steps.

Even a full increasing run followed by the next decreasing branch need not
return below the starting seed: `T(27)=41` and `T^2(27)=31>27`.
These facts are scoped to this normal form and its induced map. They do not
exclude other unequal-time bridges or additional decreasing invariants.

## 7. Reproduction and interfaces

Run from the repository root:

```
python3 experiments/residual_progress/bridge_normal_form/check_normal_form.py
```

The default is read-only and compares its deterministic output with
`normal_form_audit.json`. `--write-receipt` regenerates that receipt.
The check covers16,384 odd seeds,2,048 exact normalization currents, all
inverse predecessors below16,383 for6,143 target states,14,476 exact counting
cases,129 instances of (11), and the explicit ascent family through a=1025.
All loops have finite specified bounds or a proved decreasing/finitely
bounded parameter. No absorption search is used.

`normal_form.py` exposes normalization, exact bridges, quotient transport,
the full inverse-ray description, finite inverse enumeration, and exact
counts. Other constructors may reuse nu and its current after an explicitly
derived return; (4) then retains every boundary term. The complete elementary
component theorem prevents treating the old R23 bridge alone as a solution
of its complementary branch.
