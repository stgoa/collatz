# For the odd-value sequence of a 3x+1 invariant, 2-automatic and 3-automatic are equivalent

## Statement

Let `b` satisfy, for every `n ≥ 0`,

```
b(3n) = b(4n),   b(3n+2) = b(2n+1),   b(4n+2) = b(n),
```

the scalar interface of [`scalar-interface-three-identities`](scalar-interface-three-identities.md), and put `c(n) = b(2n)`. Then:

1. if `b` has a finite ternary kernel, so does `c`;
2. the union of the ternary kernels of `b` and `c` is closed under binary sections;
3. hence a 3-automatic `b` is 2-automatic; with V004's `K_3(b) ⊆ K_+(ext b)` the converse holds, so **`b` is 2-automatic iff it is 3-automatic**, with no external input;
4. `K_2(ext b) ⊆ {ext b} ∪ K_2(b)` for the odd-part extension `ext b(x) = b((oddpart(x) − 1)/2)`;
5. given Cobham's theorem, a 3-automatic (equivalently 2-automatic) `b` is constant.

Automatic means finite kernel (Eilenberg's characterisation taken as the definition, as in V004).

## Proof

From [`separator.md`](singleton-exit-separator-exclusion/separator.md) §1.1. (1): write `2r = q·3^a + s` with `q ∈ {0, 1}`, `0 ≤ s < 3^a`; then `c(3^a n + r) = f(2n + q)` for the ternary section `f(n) = b(3^a n + s)`. (2): for `a ≥ 0`, `0 ≤ r < 3^a`, `i ∈ {0, 1}` and `v = 3^a i + r`,

```
E_i[b(3^a n + r)] = c(3^a n + v/2),               v even,
E_i[b(3^a n + r)] = b(3^(a+1) n + (3v+1)/2),      v odd,
E_i[c(3^a n + r)] = b(3^a n + (v−1)/2),           v odd,
E_i[c(3^a n + r)] = b(3^(a+1) n + 3v/2),          v even,
```

using the definition of `c` and the second, third and first identities; every offset is nonnegative and strictly smaller than its displayed power of 3. So the binary sections of `b` stay in a finite set when `K_3(b)` is finite. (3)–(4): the forward direction via [`positive-offset-kernel-ternary-closure`](positive-offset-kernel-ternary-closure.md) (`K_3(b) ⊆ K_+(ext b) ⊆ K_2(ext b)`) and the reconstruction `K_D(h) = {h} ∪ K_(D−1)(b)` of V005. (5): Cobham makes `b` eventually periodic, and [`odd-eventually-periodic-invariants-constant`](odd-eventually-periodic-invariants-constant.md) finishes. ∎

## Remarks

- This lemma supplies the ternary half of hypothesis (I) of [`singleton-exit-separator-exclusion`](singleton-exit-separator-exclusion/README.md): every positive binary section of a nonconstant invariant has infinite kernels in both bases (conditional on Cobham through V004/V005).
- **Controls.** For `d = 5` or `61` the divisibility invariant `1_{d|n}` has finite kernels; the `d = 1` scalar identity fails on it (`b_5(3n) = 0`, `b_5(4n) = 1` at `n = 3`), so the controls fail the hypotheses here.
