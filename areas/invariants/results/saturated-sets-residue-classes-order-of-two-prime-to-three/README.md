# Every saturated set of `3x+1` meets every residue class modulo `2^k·3^b·M′` when 3 does not divide the order of 2 modulo `M′`

## Statement

`T` is the Collatz map on `Z_(>0)`; `B ⊆ Z_(>0)` is **saturated** if `x ∈ B ⟺ T(x) ∈ B` (a union of orbit components, the sets of the question [`invariant-sets-meet-every-residue-class`](../../questions/invariant-sets-meet-every-residue-class.md)). For `M′` coprime to 6 write `ord_(M′)(2)` for the multiplicative order of 2 modulo `M′`; `3 ∤ ord_(M′)(2)` holds iff `3 ∤ ord_p(2)` for every prime `p | M′` (the order modulo `M′` is the least common multiple of the orders modulo the prime powers, and the order modulo `p^c` is `ord_p(2)` times a power of `p`).

**Theorem.** Let `M′` be coprime to 6 with `3 ∤ ord_(M′)(2)`. For every nonempty saturated `B`, all `k, b ≥ 0` and every residue `r` modulo `M = 2^k·3^b·M′`, `B` contains an element `≡ r (mod M)`.

Among the primes below 200 the hypothesis fails exactly for `7, 19, 37, 73, 109, 163` (`ord_p(2) = 3, 18, 36, 9, 36, 162`). Together with [`saturated-sets-meet-residue-classes-six-smooth-moduli`](../saturated-sets-meet-residue-classes-six-smooth-moduli/README.md) (`M′ = 1`) and the finite search of [`saturated-sets-meet-residue-classes-small-moduli`](../saturated-sets-meet-residue-classes-small-moduli/README.md) (every individual `M ≤ 100`), the statement of the question is now proved for every `M ≤ 100` and for every `M` whose part prime to 6 has `3 ∤ ord(2)`.

**The two composite moves.** For odd `z ∈ B` and `s ≥ 1`,

```
σ_s(z) = 4^s·z + (4^s − 1)/3        (forward step, 2s doublings, one inverse step),
ι_j(z) = (2^j·z − 1)/3              (j doublings, one inverse step; legal iff 2^j·z ≡ 1 (mod 3)).
```

Both stay in `B` and produce odd integers. In the coordinate `w = 3z + 1` they read `w ↦ 4^s·w` and `w ↦ 2^j·(w − 1)/3`.

## Proof

Throughout, `B` is saturated and nonempty, and the moves of Lemma 1 of the six-smooth node are used: `x ∈ B ⇒ 2x ∈ B`; odd `x ∈ B ⇒ 3x + 1 ∈ B`; `x ∈ B`, `x ≡ 4 (mod 6) ⇒ (x − 1)/3 ∈ B`; and `B` contains an odd element.

**Lemma 1 (scalings).** For odd `z ∈ B` and `s ≥ 1`, `σ_s(z) = 4^s·z + (4^s − 1)/3 ∈ B`, it is odd, `3σ_s(z) + 1 = 4^s(3z + 1)`, and `σ_s(z) ≡ z + s (mod 3)`.

*Proof.* `3z + 1 ∈ B` (forward, `z` odd) is even; `X = 4^s(3z + 1) ∈ B` (doublings) is even and `≡ 3z + 1 ≡ 1 (mod 3)`, so `X ≡ 4 (mod 6)` and `(X − 1)/3 = 4^s·z + (4^s − 1)/3 ∈ B`. It is odd: `4^s z` is even and `(4^s − 1)/3 = 1 + 4 + … + 4^(s−1)` is a sum of `s` odd terms, hence `≡ s (mod 2)`… more precisely `(4^s − 1)/3 ≡ s (mod 3)` because each term is `≡ 1 (mod 3)`, and `4^s z + (4^s−1)/3` is odd because `4^s − 1 ≡ 3 (mod 6)` gives an odd quotient. The identity `3σ_s(z) + 1 = 4^s(3z + 1)` is immediate. ∎

**Lemma 2 (inverses).** For `z ∈ B` and `j ≥ 1` with `2^j·z ≡ 1 (mod 3)`, `ι_j(z) = (2^j·z − 1)/3 ∈ B` and it is odd. The condition holds iff `z ≢ 0 (mod 3)` and `j ≡ 0 (mod 2)` for `z ≡ 1 (mod 3)`, `j ≡ 1 (mod 2)` for `z ≡ 2 (mod 3)`.

*Proof.* `X = 2^j z ∈ B` is even and `≡ 1 (mod 3)`, so `(X − 1)/3 ∈ B`, odd since `X − 1 ≡ 3 (mod 6)`. The parity statement is `2^j ≡ (−1)^j (mod 3)`. ∎

**Lemma 3 (free steering).** Assume `3 ∤ ord_(M′)(2)`, so `3 ∤ ord_(M′)(4)`. For every odd `z`, every `B ≥ 0` and every class `τ ≡ 1 (mod 3)` modulo `3^(B+1)`, there is `s ≥ 1` with `4^s ≡ 1 (mod M′)` and `4^s(3z + 1) ≡ τ (mod 3^(B+1))`. Consequently `σ_s(z) ≡ z (mod M′)` and `3σ_s(z) + 1 ≡ τ (mod 3^(B+1))`; in particular, with `B = 1`, the class of `z` modulo 3 can be changed to any value without changing its class modulo `M′`.

*Proof.* `4` generates the units `≡ 1 (mod 3)` modulo `3^(B+1)` (Lemma 2 of the six-smooth node: 2 has order `2·3^B`, so 4 has order `3^B`), and `3z + 1`, `τ` are such units, so `4^(s₀)(3z + 1) ≡ τ (mod 3^(B+1))` for some `s₀` modulo `3^B`. Since `gcd(3^B, ord_(M′)(4)) = 1`, the Chinese remainder theorem gives `s ≥ 1` with `s ≡ s₀ (mod 3^B)` and `s ≡ 0 (mod ord_(M′)(4))`. ∎

**Lemma 4 (transitivity modulo `M′`).** Let `𝒢` be the set of permutations of `Z/M′` induced by the affine maps `σ_s : z ↦ 4^s·z + (4^s − 1)/3` (`s ≥ 1`) and `ι_j : z ↦ (2^j·z − 1)/3` (`j ≥ 1`) (all coefficients are units modulo `M′`). The group generated by `𝒢` contains the translation `z ↦ z + 2/3`, hence all translations, hence acts transitively on `Z/M′`; and every element of this group is a product of elements of `𝒢` (no inverses needed).

*Proof.* In `w = 3z + 1`: `σ_s(w) = 4^s w`, `ι_j(w) = 2^j(w − 1)/3`. Then `ι_j ∘ σ_s ∘ ι_j^(−1) ∘ σ_s^(−1)(w) = w + 2^j(4^s − 1)/3`: indeed `σ_s^(−1)(w) = w/4^s`, `ι_j^(−1)(v) = 3v/2^j + 1`, so the composite is `ι_j(3w/2^j + 4^s) = w + 2^j(4^s − 1)/3`. With `s = 1`, `j = 1` this is `w ↦ w + 2`, a translation by a unit (`M′` is odd), so its powers give every translation of `Z/M′`, which act transitively. In a finite group every element has finite order, so inverses of generators are positive powers of them and every group element is a positive word in `𝒢`. ∎

**Lemma 5 (realisation).** Assume `3 ∤ ord_(M′)(2)`. Every positive word in the generators `𝒢` can be applied to any odd `z ∈ B` as a sequence of legal moves whose effect modulo `M′` is the word's permutation, and whose result is odd.

*Proof.* A factor `σ_s` is legal from every odd element (Lemma 1). Before a factor `ι_j`, if the current odd `z` has `z ≡ 0 (mod 3)` or the wrong parity of `j` (Lemma 2), apply a scaling `σ_(s′)` from Lemma 3 (`B = 1`) that moves `z` modulo 3 to the class making `ι_j` legal and is the identity modulo `M′`; then apply `ι_j`. ∎

**Proof of the theorem.** Write `P(k, b)` for: `B` contains, for every odd class `u` modulo `2^k`, every `ε` modulo `3^b` and every `ρ` modulo `M′`, an odd element `≡ u, ε, ρ` respectively (for `k = 0` the first condition is empty).

*`P(1, b)` for all `b`.* Take an odd `x₀ ∈ B`. By Lemma 4 some positive word in `𝒢` maps `x₀ mod M′` to `ρ`; by Lemma 5 it is realised by legal moves, giving an odd `z ∈ B` with `z ≡ ρ (mod M′)`. By Lemma 3 with `B = b` and `τ = 1 + 3ε`, a scaling gives an odd element `≡ ρ (mod M′)` with `3(·) + 1 ≡ 1 + 3ε (mod 3^(b+1))`, i.e. `≡ ε (mod 3^b)`.

*The lift `P(k, b) ⇐ P(k − 1, b + 1)` (all classes modulo `2^(k−1)`, odd or even).* As in the six-smooth node with `j = 1`: for an odd target `u` modulo `2^k` take `y ∈ B` with `y ≡ (3u + 1)/2 (mod 2^(k−1))`, `y ≡ 2^(−1)(1 + 3ε) (mod 3^(b+1))`, `y ≡ 2^(−1)(1 + 3ρ) (mod M′)` (an even class modulo `2^(k−1)` is reached by doubling an element of the right class modulo `2^(k−2)`, and so on); then `2y ≡ 4 (mod 6)` and `z = (2y − 1)/3 ∈ B` is odd with `3z + 1 = 2y ≡ 3u + 1 (mod 2^k)`, `≡ 1 + 3ε (mod 3^(b+1))`, `≡ 1 + 3ρ (mod M′)`, so `z ≡ u, ε, ρ`. Even targets modulo `2^k` are doublings of elements of the corresponding classes. Induction on `k` finishes the proof. ∎

**Where the hypothesis enters.** Only in Lemma 3: the exponent `s` must satisfy a congruence modulo `3^B` (the 3-adic target) and a congruence modulo `ord_(M′)(4)` (trivial action modulo `M′`), which is solvable for all `B` iff `3 ∤ ord_(M′)(4)`. When `3 | ord_(M′)(2)` a scaling that steers the 3-adic class acts modulo `M′` by an element of a coset of `⟨4^(3^v)⟩` (`3^v ∥ ord_(M′)(4)`), and the proof as written does not go through; the finite search of the small-moduli node shows the statement nevertheless holds for `M = 7, 19, 37, 73` and their multiples up to 100.

## Certificates

[`check_order_prime_to_three.py`](check_order_prime_to_three.py) (standard library, about 90 s) instantiates the proof and replays it: **V1** for each of the seventeen `M′ ≤ 100` with `gcd(M′, 6) = 1` and `3 ∤ ord_(M′)(2)`, from every odd start `x₀ ≤ 21`, for all `k ≤ 2`, `b ≤ 1` (`k ≤ 3`, `b ≤ 2` for `M′ = 5, 11`; `k ≤ 2`, `b ≤ 2` for `M′ = 25`) and all classes modulo `2^k·3^b·M′`: the word is found by breadth-first search in the group of Lemma 4, realised with the parity fixes of Lemma 5 and the steering of Lemma 3, lifted as in the theorem, and every move (`D`, `F`, `I`) is replayed on the integer with its legality checked (`F` needs an odd input, `I` an input `≡ 4 (mod 6)`), the end point checked for its residues: 282,953 paths, at most 1,475 moves and 9 inverse steps; **V2** for the same moduli, the group generated by `𝒢` on `Z/M′` is computed as a set of permutations (sizes 20 to 7,832), contains the translation `z ↦ z + 1/3` and is transitive (breadth-first diameters 2 or 3); **V3** for `M′ ∈ {7, 19, 37, 73}` no `s` with `s ≡ 1 (mod 3)` and `4^s ≡ 1 (mod M′)` exists, recording where the hypothesis is used (nothing is claimed about these moduli here); **V4** control: for `3x+5` the maps `σ_s(z) = 4^s z + 5(4^s − 1)/3`, `ι_j(z) = (2^j z − 5)/3` modulo 5 reach only the class 0 from 0, as they must; **V5** the receipt [`order_prime_to_three.json`](order_prime_to_three.json) (`--write-receipt` regenerates it). Finite statements only; the theorem's proof is the text above.

## Remarks

- **Reading.** Together with the six-smooth theorem, the closure of any orbit component in `∏_p Z_p` over the primes `p ∈ {2, 3} ∪ {p : 3 ∤ ord_p(2)}` is everything: no saturated set is detectable by congruences modulo such primes. The primes with `3 | ord_p(2)` have density `7/24` among all primes (Hasse); for them the coupling between the 3-adic steering and the action modulo `p` is a finite problem per prime that the search of the small-moduli node solves for `p ≤ 100`, and whose uniform solution is the remaining content of the question.
- **The mechanism.** Scalings fix the point `−1/3` (they multiply `3z + 1`), inverses move it; their commutator is a translation. The same two moves, with `3x + d` in place of `3x + 1`, give translations by `d·2^j(4^s − 1)/3` modulo `M′`: units when `gcd(d, M′) = 1`, zero modulo every prime dividing `d`. That is the exact mechanism behind the control `dZ_(>0)` for `3x+d`, and the statement for `3x+d`, `gcd(d, 6) = 1`, holds for `M′` coprime to `6d` with `3 ∤ ord_(M′)(2)` by the same proof.
- **Budgets.** The certificate's paths use at most 9 inverse steps (for `k ≤ 3`); the finite search of the small-moduli node found at most 4 inverse steps for odd `M ≤ 100`. The constructive proof is not economical: the breadth-first word in the group is short (diameter `≤ 3`), but each parity fix and each steering is a full scaling with `4^s ≡ 1 (mod M′)`, which costs `2s` doublings with `s` up to `ord_(M′)(4)·3^b`. Novelty undetermined.
