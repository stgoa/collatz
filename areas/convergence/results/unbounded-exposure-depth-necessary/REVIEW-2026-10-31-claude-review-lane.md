## What I checked

- **Definitions followed down.** `A_N` and its table (`disjoint-annular-recursion`, reviewed), `G_D(N)` and the component dual test (`depth-32-aggregate-exposure-obstruction`, reviewed in this wave; `orbit-component-current-criterion`, reviewed). The dual test was re-derived there: a current supported on arrows of `G_D(N)` has zero total divergence on any component not containing `1`, so a component of positive `A_N`-mass excludes `A_N = (I - P)J + zeta`, `zeta <= 0`.
- **Section 2.** `2^(D+4) | X` makes `y_k = 3^k X/2^k - 1` an odd integer for `k <= D + 3`, and `y_k + 1` divisible by 4 for `k <= D + 2`, so `3 y_k + 1 = 2 y_(k+1)` with exact valuation 1 for `k <= D + 2`. `X = 1 (mod 9)` and `4 | X`, `8 | X`, `16 | X` give `y_1, y_2, y_3 = 5, 17, 17 (mod 18)` in bands 4, 5, 5, coefficients `-2, +2, +2`; `y_4 = 216N - 1` is above the support. The terminal bound `(3/2)^(D-1) 144N - 1 = y_(D+2)` (since `144N = (3/2)^3 X`) shows `y_(D+3)` has no outgoing arrow. Checked numerically for `D = 1, ..., 8` and four `X` each.
- **Sections 3-4, the inverse-history invariant, re-derived.** An inverse step of valuation `a` acts on `x = uX - c` by `u' = 2^a u/3`, `c' = (2^a c + 1)/3`, `z' = (2^a z - 1)/3`, and `u = 3^(k-l) 2^(A-k)` after `l` steps of total valuation `A`. Chain points are `2 mod 3`, so extra branches start with an odd `a >= 3` and the excess `E = A - l >= 2`. Before arrival (`A < k`, hence `l < k`), `uX` is an integer divisible by 3 because `2^(k-A) | X` (`k - A <= D + 3`) and `k - l >= 1`; hence `c` is an integer, admissibility reads `3 | 2^a c + 1`, `c` stays a positive odd integer, and `u = 3^E (3/2)^(k-A) >= 9`. Positivity of `z` by comparison with `f_1(z) = (2z - 1)/3`: `f_1` maps `(3/2)^m - 1` to `(3/2)^(m-1) - 1`, the first extra step gives a strict increase, and `z > z_tilde >= 0` is preserved for `l <= k`. At arrival `u = 3^r 2^s` with `r + s = E >= 2`, so `u >= 4`; `z` is a positive integer, `u > z`; if `z` is even then `s = 0`, `u >= 9`. After arrival the denominator of `u` is `3^max(l-k,0) <= 3^(D-2)` at a history of length `l <= D - 1`, so `3^(D+2) | X - 1` makes `x - z = u(X - 1)` divisible by 3 and admissibility transfers to `z`; the new `z` is a positive integer, odd after one step. The invariant `c > 0`, `u >= 4`, `(z = 5 => u >= 6)`: `a >= 2` gives `u' >= 16/3`; `a = 1` needs `z = 2 mod 3`, so `z = 5` (then `u' = 2u/3 >= 4`) or `z >= 11` (then `u > 11`, `u' > 22/3`); `z' = 5` forces `2^a z = 16`, `z = 1`, `a = 4`, `u' = 16u/3 >= 64/3 > 6`; an even arrival has `u >= 9` and its successor `u' >= 6`. All of this is as written.
- **Section 5.** `x = u(X - 1) + z > 4(X - 1) > 27X/8 - 1 = 144N - 1` for `X > 24/5`; so no extra-branch ancestor within `D` steps is a source, hence no extra incoming exposed arrow at any chain point. The bottom valuation-1 predecessor `X - 1` is a multiple of 3: coefficient zero and no odd predecessor. Together with the terminal bound this exhausts every incident arrow.
- **Exhaustive bounded inverse histories (my code).** All extra-branch inverse histories of length `<= D` from every chain point with valuations up to a cap, at the smallest admissible `X` for `D = 1, ..., 6` (24, 121, 309, 904, 1904, 3477 histories) and at `X = 2^18`, two further `X`: every state satisfies the affine form, `u >= 4` (the minimum `4` is attained), `z > 0`, `x > 4(X - 1)`, non-source, excess `>= 2`, the pre-arrival shape (`c` odd positive integer, `u >= 9`), the transfer `x = z (mod 3)` at and after arrival, the even-arrival bound `u >= 9`, oddness after arrival, and `z = 5 => u >= 6`.
- **Brute-force exposure graphs from every source** (no inverse reasoning): the component of `y_3` is exactly the chain with sources `-2, +2, +2`, mass 2, `1` absent, at `D = 1, ..., 5` for the smallest admissible `X` (`N = 312, 1608, 5496, 11328, 11328`), at `D = 1, 2, 3` for the second `X` (`N = 960, 3552, 11328`), and at the ray cutoff `X = 2^18`, `N = 6144`. My inverse oracle (validated against the brute force on 192 components in the review of `depth-32-aggregate-exposure-obstruction`) confirms the chain at `D = 1, 2, 4, 8, 12, 16, 24, 32` (CRT `X`) and at the ray cutoffs `X = 2^(2 * 3^(D+1))` for `D = 1, ..., 4` (`N = 6144`, `12 * 2^45`, `12 * 2^153`, `12 * 2^477`).
- **Required ray and ladder.** `2` has order exactly `2 * 3^(D+1)` modulo `3^(D+2)` for `D <= 60`; `2 * 3^(D+1) >= max(D + 4, 10)`; `12 * 2^(e t - 9) = 96 * 64^(3^D t - 2)` iff `e t = 6 * 3^D t`, which is the definition of `e`; for `k < 2000`, `X = 2^(6(k+2))` satisfies both hypotheses with `D = v_3(k + 2)` whenever that is `>= 1`, and `v_3(64^(k+2) - 1) = 2 + v_3(k + 2)` exactly; `d*(N) >= D + 1` because `G_D' subset G_D` for `D' <= D`.
- **The question it answers.** `uniform-aggregate-exposure-depth` asks for one `D` that works for every five-ray cutoff of the whole packet "or annulus". The theorem gives, for every `D`, infinitely many cutoffs on the ray `96 * 64^k` (mantissa 12, `r = 3`) where the annulus fails, which negates the annulus form of the question; the question node records that only the annulus form is answered.
- **Certificates** (`python3 tools/run_certificates.py --node unbounded-exposure-depth-necessary`, exit 0, 28 s wall): `check_unbounded_exposure.py` PASS 0 s; `check_symbolic_lift.py` PASS 1 s; `check_legacy_replay.py` PASS 26 s (replays `check_inverse_exposure.py` and the side lane's `depth_probe.py` unmodified).

## Findings

1. (imprecision) `check_unbounded_exposure.py` and `check_symbolic_lift.py` check by `assert`, so they are vacuous under `python3 -O`, contrary to AGENTS.md section 6; the node says so ("run them without -O"). Not changed here.
2. (remark) The hypothesis `X = 1 (mod 3^(D+2))` is stronger than the proof uses: the transfer step needs `3 | u(X - 1)` with denominators at most `3^(D-2)`, so `v_3(X - 1) >= max(2, D - 1)` suffices. This is exactly the refinement recorded in `delayed-release-cancellation`, section 5; the claim as stated is correct.
