- **Theorem 2.1, re-derived.** The sources of `ν_N` are odd `x` with `1 < x ≤ n_1 ≤ (3·2^b + 1)/2 < 2^(b+1)`, so they are distinct residues modulo `2^(b+1)`. The odd `x` whose first `d` valuations form the word `w` (total `A`) are one class modulo `2^(A+1)`, `x_t = q_w + 2^(A+1)t`, with `d`-step image `y_t = (3^d x_t + C_w)/2^A = e_w + 2·3^d t`. Only `t = 0` can have `x_0 = 1` or `y_0 = 1`, and a visit to 1 before step `d` forces `y = 1`; so starting at `t_0 ∈ {0, 1}` drops exactly the sources that `P^d` kills. Within a component the admissible `t` form an interval, consecutive lifts differ by `2^(A+1) ≡ ±1 (mod 3)`, so a triple carries each residue once and its weights are a permutation of `(−1, −1, 2)`; at most two lifts remain, with absolute weights summing to at most 3 (the cyclic pairs give 2, 3, 3), so at most 6 per word, and there are `Σ_(A=d)^b binom(A−1, d−1) = binom(b, d)` words. The classes modulo `2^(b+1)` covered by words with `A ≤ b` number `Σ_A binom(A−1, d−1)·2^(b−A) = Σ_(j≥d) binom(b, j)` (position of the `d`-th one in a `b`-bit string), so `Σ_(j<d) binom(b, j)` classes have `A > b`; their sources carry weight at most 2 each (the two components never both give `+2`), and `P^d` is an `ℓ¹` contraction. Hence `‖η̂_(d,N)‖₁ ≤ 6·binom(b,d) + 2·Σ_(j<d) binom(b,j) = D*_(b,d)`.
- **Corollary 2.2, re-derived.** `D*_(b,m) ≤ 8·Σ_(j≤m) binom(b,j) ≤ 8·2^(b·H₂(m/b)) ≤ 8·2^(7b/9)`, using `m/b ≤ 2/9 < 1/2` and `H₂(2/9) < 7/9`, which is `9^9 < 2^9·7^7` (`387420489 < 421654016`). With `2^b < 2N` and `8·2^(7/9) < 16` (`8^9·2^7 = 2^34 < 2^36 = 16^9`) this is `≤ 16·N^(7/9)`. For (2.6): `3E_T = Σ_(j<T) ⟨1, P^j ν_N⟩`; `|⟨1, ν_N⟩| ≤ 8 ≤ D*_(b,m)`, and for `1 ≤ j ≤ m`, `⟨1, P^j ν_N⟩ = ⟨1, η̂_(j,N)⟩` because every packet sums to 0, with `|·| ≤ D*_(b,j) ≤ D*_(b,m)` (monotone in `j ≤ m ≤ b/2`); for `T > m`, `3E_T = Σ_(j<m) ⟨1, P^j ν_N⟩ + H_(T−m)(Π̂_(m,N)) + H_(T−m)(η̂_(m,N))` and `|H_(T−m)(η̂)| ≤ (T−m)·‖η̂‖₁`. Total `≤ T·D*_(b,m)`. On `T ≤ ceil((b+1)N^(1/5))`: `T·D* ≤ (b+2)N^(1/5)·16N^(7/9) = 16(b+2)N^(44/45)`.
- **Brute force** (`review_snapshot.py` in my scratch folder, 128 s): for `8 ≤ N ≤ 600` and every `1 ≤ d ≤ b/2` (2,313 cases), and for `N = 4096, 10001, 65536` (all `d`) and `262144` (`d = 4`), I classified every source by its actual first-`d` valuation word and grouped the consecutive lifts of each (component, word) class in threes from the smallest admissible lift. In every case: consecutive lifts differ by `2^(A+1)` and their images by `2·3^d`; every triple has weights `(−1, −1, 2)`; `Π̂ + fringe + tail = P^d ν_N` exactly; the number of words is `≤ binom(b,d)`, the over-budget sources `≤ Σ_(j<d) binom(b,j)`, and `‖η̂‖₁ ≤ D*` (largest ratio 0.607). The brute-force `Π̂` equals `data/packets_4096.csv` and `data/packets_262144.csv` exactly (`η̂` norms 42 and 411 against `D* = 422` and `20336`). The two counting identities hold for `b ≤ 40`, and the over-budget class count for `b ≤ 12` by enumeration. For `9 ≤ b ≤ 3000`: `D*_(b,m) ≤ 8Σ_(j≤m) binom(b,j)`, `D*^9 ≤ 16^9·2^(7(b−1))` (so `D* ≤ 16N^(7/9)` for every `N > 2^(b−1)`), `8 ≤ D*`, and `D*_(b,d)` is monotone for `d ≤ m`; the ratio `D*/(16·2^(7(b−1)/9))` is at most 0.198 for `b ≤ 1000`.
