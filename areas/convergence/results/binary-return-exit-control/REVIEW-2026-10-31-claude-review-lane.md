## Findings

1. **Statement 4 and "Complete raw-target test" (imprecision).** "For fixed `(h, a)` it fails for all large `r`" understates the computation: for `a = p` the bracket `2^27·M^r·2^(E+a) − 6·3^(ℓ+18)·A^r` is already negative at `r = 0` for all 19 rows, so the raw stop below the original `Q` never occurs at the minimal next valuation; it needs `a > p` (for example `(1,30,6)` has `y < Q`). Not an error, the stated claim is weaker.
2. **Statement 1 (imprecision).** The quotient identity `T^12(3v) = 3Φ(v)` is correctly restricted to the re-entry cylinder: on the broader word cylinder `v ≡ 133797 (mod 2^19)` with `19 ≤ h ≤ 36` it held in only 157 of 600 random samples and never at `h = 19` (0 of 282), because `3Φ(v)` need not be canonical when `Φ(v)` leaves the guard. The ordinary words still hold there. One sentence saying the restriction is necessary would help; no change.
3. **Statement 3 (imprecision).** The pair index `b = Q/3` of the original source is a `W9` index (`Q ≡ 11 (mod 16)`), not a `W5` one; the text writes `P(b)` without saying so. No change.
