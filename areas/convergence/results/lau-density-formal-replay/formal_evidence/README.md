# Completed formal replay evidence

Source compilation, exact statement/axiom checks and fresh replay into an empty
instance of the same Lean kernel all completed with exit0 and PASS. The summary
and hashes are in [formal_replay.json](../formal_replay.json). This is independent
of the author pipeline, but uses the same kernel implementation. It is not a
second-kernel verification or an independent rebuild of every Mathlib dependency.

The pinned source and dependencies are described in [lau_scope.md](../lau_scope.md)
and [replay_notes.md](../replay_notes.md). `source_snapshot.json` compares all753
original archive files. `static_source_audit.json` is a lexical/import scan;
`statements_status.json` and `statements.log` contain actual eight axiom reports
and four paired statement comparisons. `kernel_status.json` records fresh replay
of imported private proof bodies. Cache receipts describe dependency retrieval.

The original build receipt was generated by the preserved initial runner. The
later seal records the current proof-object inventory and binds the original
receipt/log; it does not retroactively invent build-end object hashes. The
statement and kernel stages bind their predecessor receipts and object inventories.
Copies here preserve receipt bytes and original temporary paths. The summary maps
these copies to the original artifacts. Temporary paths need not remain available;
source/toolchain/dependency pins and reproduction instructions are retained.

The `.sb` profiles and environment file are the actual macOS execution configuration.
The proof profile denies network, user-directory reads, unrelated temporary-directory
reads and writes outside the two replay directories, apart from devices. Smoke and
denial receipts test these boundaries. This is not a hermetic container.

`UPSTREAM_LICENSE.txt` preserves the pinned source's Apache2.0 license, including
for challenge declarations copied into `StatementAudit.lean`. The preparation
manifest pins the earlier preparation subset; the completed summary pins all files.
