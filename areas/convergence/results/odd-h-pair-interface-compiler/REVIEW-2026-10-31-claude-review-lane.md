## Findings

1. §4, proof of the finite compiler theorem, "Every finite weak component disjoint from 1 has divergence sum zero, so x must lie in the absorbing component. Its actual forward path uses only existing nonzero current rows" — **gap**. The component argument does not by itself show that the forward orbit of `x` stays in the support of a *signed* current. The statement is true: let `J` be a finite signed current with `div J ≥ 0` (atom at 1 killed) and `(div J)(x) ≥ 1`. Put `N = {J < 0}`. For `y ∈ N`, `div J(y) ≥ 0` gives a predecessor of `y` in `N`; following predecessors inside the finite set `N` repeats a state, so every element of `N` lies on a cycle `Z ⊂ N` of `S` (forward images of periodic points are periodic). Summing `div J` over any cycle `Z` leaves `−Σ J(y)` over the predecessors `y ∉ Z` of `Z`; since such a `y` with `J(y) < 0` would lie on its own cycle, which must be `Z`, every outside predecessor of a cycle has `J(y) > 0`, so a cycle receives no outside flow and has `div J = 0` on it. Now take the least `i` with `J(x_i) ≤ 0` on the orbit `x_0 = x, x_1, …`: if `i = 0`, `div J(x_0) ≥ 1` forces a negative predecessor, so `x_0` lies on a cycle with `div J(x_0) ≥ 1`, impossible; if `i ≥ 1`, `J(x_(i−1)) > 0` and `div J(x_i) ≥ 0` force another negative predecessor, so `x_i` lies on a cycle receiving the outside flow `J(x_(i−1)) > 0`, impossible. Hence `J > 0` along the orbit, which therefore stays in the finite support and cannot enter a cycle (same sum), so it reaches 1. No global no-cycle assumption is used, as the node says. The theorem and the Collatz-equivalence stand.
2. Statement item 2, "Parent clock `k + 1 + max(ℓ, A)`" — **imprecision**: `A` is defined only in the proof (`A = r+1` direct, `r+2` nondirect, `r = v₂(3z+1)`). Definition inserted.
