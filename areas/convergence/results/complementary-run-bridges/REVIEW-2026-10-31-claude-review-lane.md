## What I checked

- **Certificates.** `python3 tools/run_certificates.py --node complementary-run-bridges`: both PASS, exit 0; [`check_run_bridge_recompute.py`](check_run_bridge_recompute.py) under 1 s, [`check_legacy_replay.py`](check_legacy_replay.py) 7 s (replays `check_run_bridge.py` and `run_bridge_check.py` unmodified, all files unchanged); 7.42 s wall in total.
- **§1, (1)-(5).** `z = 3^(a−1) t ≡ −3^(2a−1) ≡ 1 (mod 4)` gives `d ≥ 2`. `S^(a−1)(x) = 2z − 1` after `a − 1` valuation-1 steps; `3(2z − 1) + 1 = 2(3z − 1)` and `3z − 1 = 3·2^d w + 2 = 2(3·2^(d−1) w + 1)` with an odd bracket: (1). (2): `3(C 2^e w + 1) + 1 = 4(3C 2^(e−2) w + 1)`, bracket odd iff `e ≥ 3`. Odd `d`: from `e = d − 1` (even), `(d−3)/2` applications leave `e = 2`, `C = 3^((d−1)/2)`, state `4z + 1`, then `S(4z+1) = S(z)`: `a + (d−1)/2` steps, (3). Even `d`: `d/2 − 1` applications leave `e = 1`: `r = 2·3^(d/2) w + 1 ≡ 3 (mod 4)`, (4). (5) telescopes (odd branch: `Σ_(j<a+(d−1)/2) δ_(S^j x) − δ_z`).
- **§2, (6)-(9).** (6) by clearing denominators (`3^b(3^(a−1) t − 1) < 2^d(2^a t − 1)`, resp. `2·3^b(3^(a−1) t − 1) + 2^d < 2^d(2^a t − 1)`); (7) likewise; `x = H` would force `f(x) = N`, impossible for odd `f(x)` and even `N`. Odd `d`, `a ≤ 5`: at `t = 1` the condition is `(2^a − 1)2^d > (3^(a−1) − 1)3^b` (`a = 5, d = 3`: `248 > 240`), larger `d` or smaller `a` only widens it, and the positive `t`-coefficient makes `t = 1` the worst case. Nonnegativity of `T_N`: the path current from `z` cancels the row `−δ_z` of `D_x`. For the signed normalised bridge the node invokes R23's finite component lemma; I re-derived it: in the graph of nonzero rows (out-degree at most 1, row 1 killed) a weak component without 1 has total divergence 0, so a nonnegative divergence vanishes on it; a weak component containing a vertex of out-degree 0 is an in-tree to that vertex (walking away from it every edge is an in-edge), hence the component of 1 is an in-tree to 1 and every source has a directed path to 1 along the specified edges.
- **§3, (10) and the count.** `v₂(3^(a−1) t − 1) = d` iff `3^(a−1) t ≡ 1 + 2^d (mod 2^(d+1))`; this residue forces `t ≡ 3^(a−1) ≡ −3^a (mod 4)`, so every cylinder is complementary, and `a = v₂(x+1)` then `d` are determined: a partition. The CRT with `m/4` odd and both residues `≡ 3 (mod 4)` is as stated; `a ≤ A_N` and `d ≤ log₂(3^(a−1) t_max − 1)`.
- **§4, (11)-(14).** `L_(a,d)` is `f/x` to leading order. The weighted cylinder density is `(4/12 + 2·4/36 + 2·4/36)/P = (7/9)/P` in `(N, 9N/8)` and `(2·4/12)/P = (2/3)/P` in `(9N/8, 3N/2)`; `max g = 7/72 + 18/72 = 25/72`; `Σ_(a,d≥2) 2^(−a−d−1) = 1/8`, so `25/576` is the whole leading complementary mass. (12): `n − 3` pairs with `a + d = n`, and `Σ_(n>K) (n−3)/2^(n+1) = (K−1)/2^(K+1)` from `Σ_(n≥M) n/2^n = (M+1)/2^(M−1)`. (14): `H − N/L = 2^a/3^(a−1) − 1 ∈ (−1, 1/3]` for odd `d`, in `(−3, 1/3)` for even `d` with `L > 1/2` (for `L ≤ 1/2` both endpoints exceed `3N/2`); per pair `6(1 + 3/32) < 7`; `(K−3)(K−2)/2` pairs; `N·tail < 1`.
- **§5, (15)-(18).** In a cylinder `t` advances by `2^(d+1)`, so `f` advances by `2·3^(a−1+b)` (odd `d`) or `4·3^(a−1+b)` (even): `G = gA`. (15): `j = (sq + o − f0)/(gA)` must be an integer with `Pj ≡ r − x0 (mod 4m)`; multiplied by `A` the condition mod `4mA` splits into mod 4 (automatic: `P/g ≡ 0` and `r ≡ x0 ≡ 3`) and mod `mA`, which is (15); the 2-adic part `g | sq + o − f0` is automatic for odd `d`, and for even `d` forces `k = 0` with `q ≡ 3 (mod 4)` on the non-partner ray or `f = 2q + 1` on the partner ray, exactly as the text counts. (16): `ν(F^k q) = ν(F^k(2q+1)) = q` with densities `(1/2)4^(−k)`, `(1/4)4^(−k)`, and `q < N` is `x < N·4^k/L`, resp. `x < 2N·4^k/L`; for even `d`, `r = 2u + 1` is selected iff `u` is canonical (half of odd `u`), giving `[g(1/L) + g(2/L)]/2`; the geometric tail is `(25/72)(1/2 + 1/4)Σ_(k'≥k) 4^(−k') = (25/72)4^(−k)`. (18): each stratum count is a difference of two canonical counts, each within `⌊log₂(N+1)⌋ + 1/2` of its leading value uniformly in the modulus (normal-form node, (13)); the endpoint offset `(L − 3^b/2^d − o)/s` lies in `(−4, 4)` when `L/s < 2` and the stratum is empty when `L/s ≥ 2`; `O(log² N)` cylinders, `O(log N)` depths, eight rows: `O(log⁴ N)`.
- **§6.** `v₂(3^(a−1) − 1) = 2 + v₂(a − 1) = 3` for `a − 1 ≡ 2 (mod 4)`, so `f = (3^a − 3)/8`; `3` has order 16 mod 64 and `3^7 ≡ 11`, so `a ≡ 7 (mod 16)` gives `f ≡ 1 (mod 8)`. `27: (2, 2)`, `S²(27) = 31`; `31: (5, 4)`, `S⁶(31) = 91`; `91: (2, 2)`; a label-first potential would need `rank(2,2) > rank(5,4)` and the reverse.

## Findings

1. **§5, (18) (gap, minor).** The `O(log⁴ N)` error is proved in sketch with implicit constants. The ingredients hold (above) and the exact formula matches brute force at every tested cutoff; the claim states only `O(·)`, so this suffices, but an explicit bound in the style of (14) would make it checkable.
2. **§5, nonnegativity (imprecision).** The signed normalised bridge is made nonnegative by R23's component lemma, whose justification ("1 as its unique terminal vertex") omits the in-tree argument supplied above. Holds.
3. **§4, (14) (imprecision).** The per-progression error is quoted as `weight × (1 + 3/p)`, `p ≥ 32`, while the relevant period is `p·m/4 ≥ 96`; the bound is valid but looser than needed, and `< 7` per pair is right either way.
4. **Remarks (imprecision).** No Controls remark. The identities (1)-(5) and (10) are `d`-uniform; the tests (6)-(7), the profile and the counts are the `d = 1`-specific parts. Nothing in the node excludes the control cycles (see above).
