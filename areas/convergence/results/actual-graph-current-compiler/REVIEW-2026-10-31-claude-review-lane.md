- **The source identity, re-derived.** For `8 | N`, `n_0 = N/4 − 1`, `n_1 = 3N/2`, `n_2 = 3N/4`. Partition the odd `x` with `1 < x ≤ N` by first valuation: `v = 1` (`x = 4j+3 ↦ 6j+5`) maps bijectively onto the odd `y ≡ 2 (mod 3)`, `y ≤ n_1`; `v = 2` (`x = 8j+1`, `j ≥ 1`, `↦ 6j+1`) onto the odd `y ≡ 1 (mod 3)`, `1 < y ≤ n_2`; `v ≥ 3` (`x = 4z+1`, `z` odd `≤ n_0`) has `S(x) = S(z)`. Hence `P(U_N − U_(N/4)) = U^(2)_(3N/2) + U^(1)_(3N/4)` (residue-restricted counting measures) and `ν_N = 3P(U_N − U_(N/4)) − U_(3N/2) − U_(3N/4)`. With `D_N = 3U_N − 3U_(N/4) − U_(3N/2) − U_(3N/4)` and `K_N = ν_N + 3(U_N − U_(N/4))` this gives `D_N = 3(I−P)(U_N − U_(N/4)) + ν_N = Π_N + η_N + (I−P)K_N`, identity (6), with `Pν_N = Π_N + η_N` from [`right-aligned-fixed-core-remainder`](../right-aligned-fixed-core-remainder/README.md).
- **The compile bookkeeping, read line by line in `compile_inputs`.** For each input cutoff with weight `w_k/3` (numerator over the common denominator `d`): the current receives `J_k + K_N + (absorption current of η_N)` and the residual receives `ζ_k`; the divergence is `Π_N − ζ_k + (D_N − Π_N − η_N) + η_N = D_N − ζ_k`, so current plus residual reproduce `D_N`. The rounding shells `W_k = (U_(N_(k+3)) − U_(3N_k/2)) + (U_(N_(k+3)/2) − U_(3N_k/4)) ≥ 0` enter the residual with a minus sign (`N_(k−2) = N_(k+3)/2`), the lower-boundary counting measures (cutoffs `≤ 84 < 96`) as absorption currents, the upper-boundary ones as positive residual. The script then checks `d·U_112 = (I−P)J_num + Z_num` coefficient by coefficient and `Σ max(Z_num, 0) < d`.
- **The integer-component step, re-derived.** Let `C` be a weak component of the graph of exposed arrows not containing 1. Every arrow from `C` stays in `C`, so `Σ_C (I−P)J_num = 0` and `d·#(targets in C) = Σ_C Z_num ≤ ‖Z_num⁺‖₁ < d`, forcing no target in `C`. In the component of 1, each vertex has one out-arrow and 1 is a sink, so two sinks or a cycle and a sink cannot share a component: the component is an in-tree on 1 and every target reaches 1 along exposed arrows forwards. The routing is therefore nonnegative, and the script verifies this directly (`c > 0` for every row, support inside the exposed arrows, divergence equal to the target), independently of the lemma.
