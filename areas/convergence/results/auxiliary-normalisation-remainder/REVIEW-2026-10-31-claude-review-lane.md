## Findings

1. §2, order independence (imprecision). The recursion `F(x) = max(μ(x) + Σ_(f(y)=x) F(y), 0)` is justified only by "a negative initial coefficient first absorbs arrivals; all remaining positive mass departs". The missing sentence: a departure leaves coefficient 0 and every arrival is positive, so if `x` departs at all, no arrival can follow its last departure (another departure would be due), hence `Z(x) = 0` and `out(x) = μ(x) + in(x)`; if `x` never departs, `out(x) = 0` and `Z(x) = μ(x) + in(x) ≤ 0`. Since `f(y) < y`, descending induction gives the displayed `F`. Correct with this sentence.
2. §1, the rule for `y ≡ 17 mod 18` (remark). `r = (2y − 1)/3 < y` is already a smaller ancestor; the two-step rule to `q = (2r − 1)/3` deliberately passes over the residual at `r`, so a negative annular atom at `r` is not used for cancellation. The Remarks say so (that capacity is used in `signed-path-collapse-capacity`). `Z` and `J` depend on this choice; the proofs are for the rules as stated.
3. §5 (remark). The bound is attained for `D = 1` (`y = 13` has the smaller ancestor 11 at depth 2), but for `D = 2` no `y ≡ 1 mod 9` below 20000 has a smaller ancestor at depth 3; the first is at depth 4 (`y = 91`, ancestor 71). Reason: from `y ≡ 1 mod 9` a second inverse step of valuation 1 needs `x_1 ≡ 2 mod 3`, which forces the first valuation `≡ 4 mod 6`, so three steps multiply by at least `(16/3)(2/3)(2/3) > 1`. Not a flaw: the lemma is an upper bound on what any fixed depth can guarantee.
4. Legacy spacing typos throughout the imported note ("at least3", "valuation1", "residues1 and 7", "is2 mod3"), and the pre-migration command path in §6. Typo; not corrected.
