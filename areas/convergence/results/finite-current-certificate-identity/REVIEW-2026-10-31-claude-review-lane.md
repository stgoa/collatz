- **(i) Lag formula, re-derived.** If `τ(z) < ∞` then `τ(x_i) = d_i + τ(z)`, because the verified path avoids 1 (the case `z = 1`, `τ(z) = 0`, is included). For `L ≤ τ(z)` every `h_L(x_i) = L` and `Σ c_i = 0` kills the sum, matching `Φ(0) = 0`. For `L > τ(z)`, `min(L, d_i + τ(z)) = τ(z) + min(L − τ(z), d_i)` and the `τ(z)` terms cancel, leaving `Φ(L − τ(z))`. If `τ(z) = ∞`, all `h_L(x_i) = L`. `Φ` is piecewise linear with integer knots `d_i` and constant beyond `max d_i`, so over nonnegative integers its extrema are at `0` and the `d_i`.
- **(ii) Current identity, re-derived.** `⟨1, P^j μ⟩ = Σ_x μ(x)·1[τ(x) > j]` and `Σ_(j<L) 1[τ(x) > j] = min(L, τ(x))`, which is (1.1). Telescoping gives `⟨1, J − P^L J⟩ = Σ_y J(y)(1 − 1[τ(y) > L])`. Equivalently `h_L(y) − h_L(S y) = 1[τ(y) ≤ L]` in the three cases `τ(y) ≤ L` (values `τ(y)`, `τ(y) − 1`, with `h_L(1) = 0` when `S y = 1`), `L < τ(y) < ∞` (both `L`) and `τ(y) = ∞` (both `L`); the convention `h_L(1) = 0` is what matches the killing of mass at 1. The bounds follow from `0 ≤ 1[·] ≤ 1`, and `⟨ζ, h_L⟩ ≤ L·‖ζ⁺‖₁` from `0 ≤ h_L ≤ L`.
- **(iii) Exit profiles, re-derived.** From `y ∈ supp J` the walk leaves the finite acyclic support after `d(y) ≥ 1` steps without meeting 1, so `τ(y) = d(y) + τ(z(y))`, both sides infinite together. Substituting into (ii) and grouping by exit and distance gives `Σ_z Σ_k v_z(k)·1[k ≤ L − τ(z)] = Σ_z F_z((L − τ(z))_+)`; the cases `L < τ(z)` and `τ(z) = ∞` contribute 0, which equals `F_z(0) = v_z(0) = 0` because every `d(y) ≥ 1`. Each `F_z` lies in `[L_z, U_z]`, and `U_z ≤ Σ_k v_z(k)⁺ ≤ Σ_(z(y)=z) J(y)⁺`, so `Σ_z U_z ≤ ‖J⁺‖₁`.
