# Review of absorbed-fibre-uniform-counts

## What I checked

- Certificates: `python3 tools/run_certificates.py --node absorbed-fibre-uniform-counts` from the repository root: PASS, exit 0, 18.3 s wall; the runner reports 12 s for [`fibre_count_check.py`](fibre_count_check.py) and 6 s for [`check_legacy_replay.py`](check_legacy_replay.py) (run concurrently with the certificates of two other nodes). `git status` was clean afterwards, so [`fibre_count_check.json`](fibre_count_check.json), which the probe rewrites on every run, was reproduced byte for byte.
- Definitions: `B`, `nu`, `F` and the components from [`elementary-bridge-quotient-normal-form`](../elementary-bridge-quotient-normal-form/README.md) (reviewed). `I_N` is the union of `C_q` over canonical `q <= N` because `nu(x)` is the least member of the component of `x`.
- The conditional certificate (section 1), re-derived. The support graph of a finite current has out-degree at most 1 (one row `x -> S(x)` per vertex, none at 1), so each weak component has exactly one end, a terminal vertex or a cycle, shared by all its vertices. A component not containing 1 has total divergence 0, and `div H = U_N >= 0` then forces `div H = 0` on it; a source `q` in `[3, N]` has `div H(q) = 1`, so it is a vertex of the component of 1, whose end is the terminal vertex 1. Hence the forward path from `q` along supplied rows reaches 1, and the path current `H_q` (coefficient `+1` on each row) has divergence `[q]`. Adding `J_x` (divergence `[x] - [nu(x)]`, from R25) gives (3); the same lemma extracts a nonnegative path for `x` from `J_x + H_q`. Row count: a sibling comparison uses two rows, and the halving bridge `2a` rows with `2^a <= r + 1 <= 2N + 2`, so `a <= floor(log2(2N+2))` and (4) follows.
- The count (sections 2 and 3), re-derived. `f_s(q) = 2^s q + beta_s` equals `F^k(q)` (`s = 2k`) and `F^k(2q+1)` (`s = 2k+1`); distinct pairs `(q, s)` give distinct integers (`F` is injective, and `F^i(q) = 2q+1` or `F^i(2q+1) = q` would need `2q+1 = 5 (mod 8)` or `q = 5 (mod 8)`, impossible for `q` in `B`). (8) is the reindexed sum of `A_s(2X) - A_s(X)`, with `A_0(2X) = K(N)` because `2X - 1 >= N`. (9): `1 + 2 beta_(s-1) - beta_s` is `(2^s + 2)/3` for even `s >= 2` and `(2 - 2^s)/3` for odd `s`, so `|d_s| <= 1/2` (equality at `s = 2`, `d_1 = 0`) and each correction has magnitude at most 1. `c_s = (1 + beta_s)/2^s` is `1/3 + 2/(3*2^s)` for even `s` and `2/3 + 2/(3*2^s)` for odd `s`, so `1/3 < c_s <= 1`, giving (10) and at most `L + 1` nonzero corrections, `L = floor(log2 N)`. With `|K(N) - N/4| <= floor(log2(N+1)) + 1/2 <= L + 3/2` (R25, (13) at `m = 1`) this gives `2L + 5/2 <= 2L + 3`, (12). (13) follows since `ceil(X/2) = X/2 + O(1)`.
- Numerics with my own canonical test, `nu` by descent and `S` (script in the reviewer's scratch folder, not committed): `nu` idempotent and canonical on all odd `x < 2^17`, `nu(F(x)) = nu(x)`, `nu(2q+1) = q`; the `K` bound for all `N <= 2^18` (approached within its half unit); brute-force band counts equal to the level formula (6) and the telescope (8) in 5936 cases (`N` from 1 to 10000, `X` from `N` to `32N + 7` below `2^17`), every correction of magnitude at most 1 and inside (10), at most `L + 1` of them; (12) and (11) hold in every case with `N >= 8` (never closer than 6.75, respectively 3, to the bound) and in every tested case with `1 <= N < 8`; (12) holds for the component count at `X = N*2^e + {0, 1, 12345}`, `e` in `{20, 64, 200, 512, 1000}`, `N` in `{8, 13, 64, 100, 257, 1000, 4096, 10000}` (120 cases); (9) and the range of `c_s` exactly, as rationals, for `s < 200`.
- Hitting times (section 4): for canonical `q > 1` the members of `C_q` share the odd-only hitting time of `q` (all canonical `q < 3000`, both rays through `F^5`), and members of `C_1` reach 1 within two steps. "Neither of which reaches 1 early" is right: for selected `r = 2^a t - 1` (`a >= 2`) the first `a - 1` states of `r` and the first `a - 2` of its partner are `2^(a-i) 3^i t - 1 > 1` and `2^(a-1-i) 3^i t - 1 >= 1`, with equality only for `a = 2`, `t = 1` (the component of 1); and `S^a(q) = 1` for complementary `q = 2^a t - 1` would need `3^a t = 2^(v-1) + 1` with `3^a t = 3 (mod 4)`, forcing `3^a t = 3` and `a = 1`.
- Controls: the hypothesis "a current with `div H = U_N` is supplied" fails for `3x+5` at every `N >= 3` (3 enters the cycle through 19), for `3x+7` at `N >= 5`, for `3x+13` at `N >= 13` and for `3x+61` at `N >= 61` (first odd `q >= 3` not reaching 1, by my own iteration), so the conditional statement excludes no actual `3x+d` cycle; the count is `3x+1` arithmetic of `B` and the node defines no `d`-analogue of it.

## Findings

1. [`AGENTS.md`](../../../../AGENTS.md) §6 asks certificates not to rely on `assert`. Severity: imprecision (hygiene; the checks themselves are correct and passed).
2. Section 4, "neither of which reaches 1 early": asserted without argument; the argument above closes it. Severity: imprecision.
3. Claim and Statement 2, "X >= N >= 8": the proof nowhere uses `N >= 8` (R25's bound (13) holds from `Y >= 1`), and the bound held in my tests for `1 <= N < 8`. The stated range is correct, only narrower than what is proved; the legacy `band_count` rejects `N < 8`, which is where the hypothesis comes from. Severity: imprecision.
4. Section 3, (10): the derivation gives `2X/(N+1) < 2^s < 3X/2`; the displayed `2^s < 2X` is weaker and suffices. Severity: typo.
