## What I checked

From `3w = 1 + 2^h C` and `S(w) = 1 + 2^(h−1)C` (valuation 1 since `3w + 1 ≡ 2 mod 8`), `k` applications are legal on both paths exactly when the exponents stay `≥ 3` before each step: for `h = 2k + 2` this gives `S^k(3w) = 1 + 4·3^k C = 4z + 1` and `S^(k+1)(w) = 2z + 1`; for `h = 2k + 3`, `8z + 1` and `4z + 1`.
- **Branch O_k.** `z ≡ 3 (mod 8)` gives `3z ≡ 1 (mod 8)` canonical and `6z + 1 = 2(3z) + 1` its selected partner with `A = v₂(6z + 2) = 2`; `S(8z + 1) = 6z + 1` (valuation 2) and `S(4z + 1) = S(z)`. The difference of (left prefix + bridge of `6z + 1`) and (right prefix + sibling row `δ_(4z+1) − δ_z`) has divergence `P(w) − P(z)`, so the child is added; `z = 3^k(3w − 1)/2^(2k+3) < (3/8)(3/4)^k w < w/2`; the clock increment `k + 1` follows because for `l ≥ 2` the next `l` arrows from `6z + 1` agree with those from `3z`.
- **Branches E1_k, E2_k.** With `z = 4u + 1`: `u ≡ 7 (mod 16)` iff `z ≡ 29 (mod 64)`, and then `3u + 1 ≡ 22 (mod 48)` has valuation 1, so `w' = (3u + 1)/2 = (3z + 1)/8 ≡ 3 (mod 8)`; the right path `8u + 3 → 12u + 5 → 9u + 4 = 6w' + 1` has valuations `(1, 2)` because `9u + 4 ≡ 3 (mod 16)` is odd, and `6w' + 1` is the selected partner of the canonical `3w' ≡ 1 (mod 8)`. For E2, `u ≡ 25 (mod 32)` iff `z ≡ 101 (mod 128)`, `v₂(3u + 1) = 2`, `w' = (3z + 1)/16`, and `9u + 4 = 4(3w') + 1`. Both local currents have divergence `P(w) + P(w')`, so the child is subtracted; the bounds `w' < w/2`, `w' < w/4` follow from `z < (3/4)^(k+1) w`; the affine numerators and denominators of the table are as displayed.
- **Section 4, cylinders.** For the class (15), `3^j(3v − 1) = 2^(2j+2)(1 + 8m)` gives exactly `h = 2j + 2` and `z ≡ 1 (mod 8)`; for `j = 1` this is `v ≡ 59 (mod 128)`.
