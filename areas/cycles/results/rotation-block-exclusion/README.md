# Concatenations of rotations of one mechanical word are never integer 3x+1 cycles

## Statement

Fix any primitive positive mechanical valuation word `v`, with coprime totals `(A_0, m_0)` and `2^A_0 > 3^m_0`. Form any nonempty finite concatenation `w` of cyclic rotations of `v`. The number, order and multiplicities of the blocks are arbitrary. Then

```
den(w) > 1,
```

unless the base is `(2)`, in which case all words repeat the fixed cycle at 1. This is an all-size exclusion for the stated class. More precisely (rotation-block theorem): if `v`'s rational cycle states lie in `[l, h]` with `R = h/l < 2` ([`narrow-cycles-are-mechanical`](../narrow-cycles-are-mechanical/README.md)), every positive rational cycle generated by `w` has `H/L ≤ R³ < 8`.

## Proof

Written proof: [`ORDER_THEORY.md`](ORDER_THEORY.md) §2, "A complete exclusion for arbitrary concatenated rotation blocks". It has two parts (legacy report):

1. An integer cycle with maximum odd state less than eight times its minimum has coprime primitive totals `(A, m)`: exact odd-numerator spacing prevents inversions after dyadic normalisation in this range, and the successor becomes a transitive rank rotation ([`three-band-collatz-cycles-are-ordered`](../three-band-collatz-cycles-are-ordered.md)).
2. If the base mechanical cycle has ratio `R < 2`, every mixed block cycle has ratio at most `R³`, hence less than 8. Full blocks are contractions `f_t(x) = s·x + (1 − s)·X_t` toward points `X_t` in the base interval `[l, h]` (common slope `s = 3^m_0/2^A_0 < 1`); their prefixes (affine maps with positive slope and nonnegative intercept) preserve a multiplicative comparison with base-cycle states, so every mixed state lies in `[l/R, R·h]`. An integer mixed cycle would therefore reduce to one base block: the word's totals `(r·A_0, r·m_0)` have gcd `r`; if `w` is `p` repetitions of its primitive word, the three-band corollary forces `p = r`, so every aligned block is identical, and the cycle is the base mechanical cycle, whose exact denominator `D_0 = 2^A_0 − 3^m_0` is known from R71. That is 1 only for the base `(2)`.

This permits arbitrary changes of phase between blocks.

**Example.** Base `v = (1,2,2)` (states `(23, 37, 29)/5`, `R = 37/23`). Concatenating `v` with its rotation `(2,2,1)` gives `w = (1,2,2,2,2,1)`, `C_w = 1805`, `D_w = 295`, `gcd = 5`, reduced denominator 59. Its primitive raw `3x+59` cycle has numerators `(361, 571, 443, 347, 275, 221)`, minimum 221, maximum 571, `H/L = 571/221 < 8`. The exclusion is specific to `d = 1`.

## Remarks

- **Scope.** This removes the two-block-order restriction within this rotation class, but does not contain all C002/C003 cases, which admit nonmechanical blocks. Arbitrary cycles need not have a common mechanical block decomposition. Cycles whose blocks come from different bases, or which have no block structure, are not covered. No general denominator growth or fixed-denominator finiteness follows.
- **An infinite nonmechanical family** (written, `ORDER_THEORY.md` §2 and [`LITERATURE.md`](LITERATURE.md)): for every prime `m_0 ≥ 13` and `A_0 = bit_length(3^m_0)`, take the lower mechanical base `v_0` and its one-letter left shift `v_1`, concatenated in the label pattern `(0,0,1,0,1,1)`. The word is primitive with totals `(6A_0, 6m_0)` (gcd 6), so not mechanical; every rational state exceeds `l/R > m_0/12 > 1`; its shortcut-clock parity word has `6(A_0 − m_0)` local minima (a shortcut count, not an odd-only count). Minimum and minima count grow without bound, so the family lies outside the direct hypotheses of fixed-count exclusions ([`simons-2005-m-cycles`](../../../../sources/simons-2005-m-cycles.md), [`hercher-2023-cycle-length`](../../../../sources/hercher-2023-cycle-length.md)) and the mechanical/high-cycle exclusion ([`knight-2026-high-cycles`](../../../../sources/knight-2026-high-cycles.md)). This is not a new universal record or a novelty claim; searches for concatenations of Christoffel/mechanical rotations did not establish novelty.
- **Controls.** The worked example is a genuine `3x+59` cycle; the exclusion uses `d = 1` through R71's `g = 1` ([`mechanical-word-exact-denominator`](../mechanical-word-exact-denominator/README.md)) and the mod-8 fact `2^A − 3^m ≠ 1`.
- **Related.** The order criterion and its failed shortcut: [`dyadic-order-lemma`](../dyadic-order-lemma.md), [`mechanical-normalized-word-transfer`](../../attempts/mechanical-normalized-word-transfer.md). Next target: [`ordered-cycle-denominator-one`](../../questions/ordered-cycle-denominator-one.md).
- **Literature.** Not found in the sources read: C005's rotation-block class (side-lane literature referee, feed 08:57). Novelty undetermined.
