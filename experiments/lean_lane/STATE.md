## Statement-match notes

- Target 1: main's (1) in `invariant_colors.md` §1 is `h(2n)=h(n)` for
  `n>=1` and `h(3n+d)=h(n)` for odd `n>1`, with no identity at the absorber;
  §4/Appendix state "every periodic or eventually periodic d=1 invariant
  coloring is constant". The Lean theorem takes `h : ℕ → α`, `0 < M`,
  `∀ n, h (n+M) = h n`, `∀ n, h (2n) = h n`, `∀ n, Odd n → 1 < n → h (3n+1)
  = h n`, and concludes `∀ n, 0 < n → h n = h 1`. Hypotheses quantified
  over all of ℕ cost nothing: a colouring of the positive integers with
  period `M` extends to `0` by `h 0 := h M`, after which both all-ℕ
  hypotheses hold. So the Lean statement implies main's for every period.
  *Eventual* periodicity (Appendix, last paragraph) and the general
  `gcd(M,d)` classification are not yet formalised (queued under 1b). The
  control matches §5's `3x+5` example with the indicator of `5 ∣ n`.

- V004-i: V004 §5 assumes `b(n) = h(2n+1)` eventually periodic (from Cobham)
  and proves `h` constant; the Lean theorem takes exactly that: `0 < M` and
  `∀ n ≥ N, h(2(n+M)+1) = h(2n+1)`, with the two colouring rules as in
  target 1, and concludes `∀ n > 0, h n = h 1`. The proof differs from the
  prose in form (integer identities `b(4n+2)=b(n)`, `b(3n+2)=b(2n+1)`,
  `b(4n)=b(3n)` instead of the residue map on `Z/LZ`; period `3K ⇒ K` by
  strong induction instead of the `H^{e₃}` descent; translation by
  `c = (L+1)/2` instead of by `1/4`), but it uses only consequences of (1)
  and reaches the same statement. No finiteness of the colour set is needed.

- V004-ii: V004 §3 states that `K₊ = {n ↦ h(2^a n + r) : a ≥ 1, 0 < r < 2^a}`
  is closed under binary and ternary sections, with Case A (`3 ∤ c`,
  `v ∈ {1,2}`, `t = (2^v c − 1)/3`) and Case B (`3 ∣ c`, `t = 2^ℓ u`,
  offset `16u+1`). The Lean theorem states exactly the closure as
  identities: for `a ≥ 1`, `0 < r < 2^a`, `j < 3` there exist `a' ≥ 1`,
  `0 < r' < 2^a'` with `h(2^a(3n+j)+r) = h(2^a' n + r')` for all `n`; the
  witnesses are V004's (`a+v`, `t`) and (`s+4`, `16u+1`). It does not
  mention automata, finiteness or Cobham; those enter only in V004-iii.

- V004-iii: main's Theorem (V004 §1) is "every finite-valued binary-automatic
  `h` satisfying (1) is constant", using Cobham and the finite-kernel
  characterisation as external inputs. The Lean theorem
  `automatic_rigidity : CobhamStatement α → ∀ h, (∀ n, h(2n)=h n) → (∀ n,
  Odd n → 1 < n → h(3n+1)=h n) → KAutomatic 2 h → ∀ n, 0 < n → h n = h 1`
  makes those inputs visible in its own hypotheses: `KAutomatic k f` is
  finiteness of the kernel `{n ↦ f(k^e n + j) : j < k^e}` (the Eilenberg
  characterisation taken as definition, so no separate hypothesis is
  needed), and `CobhamStatement α` is Cobham's theorem in kernel form,
  quantified over **every** `f : ℕ → α` (never specialised to `h` or to its
  odd restriction). "Finite-valued" is not assumed separately:
  `finite_range_of_kernel2` proves that a finite 2-kernel forces a finite
  range, so `CobhamStatement α` is exactly the classical theorem over a
  finite alphabet. The proof is main's: the 2-kernel of `b(n)=h(2n+1)` sits
  inside the 2-kernel of `h`, its 3-kernel sits inside `K₊ ⊆ Kernel 2 h` by
  induction on the ternary digits with `kernel_ternary_closure`, Cobham
  gives eventual periodicity, and `odd_eventually_periodic_const` finishes.
  `#print axioms` lists only the three standard axioms because the external
  theorem is a hypothesis, not an axiom; discharging it needs a
  formalisation of Cobham's theorem, which does not exist in Mathlib.

- Item 3: `Bad n := ∀ k, collatz^[k] n ≠ 1` — the ordinary map `collatz`
  and its iterates, exactly the map and clock of the imported theorem (no
  accelerated clock is used in the conclusion). Density: natural lower
  density in explicit form, `∃ c > 0, ∃ X₀, ∀ N ≥ X₀, c·N ≤ #{n < N : 0 < n
  ∧ Bad n}`; the witnesses are `collatzDensityDep t`,
  `collatzDensityThresholdDep t` for `t = 3m+1`, `m` the odd part of the
  given bad `n` (`exists_bad_target`), so `c = 1/(t⁴·2^2^2^87640)`. The
  passage to logarithmic density (positive lower natural density ⇒ positive
  lower logarithmic density) is a standard Abel-summation fact and is **not**
  formalised. The hypothesis requires a *positive* bad `n` because `0` is a
  fixed point of `collatz` and would be "bad" vacuously. `bad_of_reach` uses
  that the orbit of 1 is the 3-cycle `1,4,2`, so a bad `t` cannot be an
  iterate of 1. `collatz_of_bad_density_zero` is the contrapositive stated
  with the same count; its hypothesis is *lower* natural density zero
  (`liminf = 0`: for every `c > 0` and `X₀` some `N ≥ X₀` has fewer than
  `c·N` bad numbers), which is weaker than density zero, so the theorem is
  correspondingly stronger (side-lane note; docstring corrected). Two elaboration notes recorded in the file: the
  tower constant must not be touched by `positivity`/`unfold`/bare `rw`
  (positivity is proved for a general `q` and closed by definitional
  unfolding), and `norm_cast` overflows on the cast inequality (replaced by
  `Nat.cast_le.mpr`).

- Item 4: R.1 states "Collatz holds iff every `w ∈ W5` has a finite exact
  current for `P(w)`; equivalently, for every positive odd `u`, the ordinary
  orbits of `u` and `18u+5` meet", via `S(4u+1)=S(u)` and `S(3(4u+1))=18u+5`
  with `w=4u+1`. The Lean file proves the two identities for the library's
  `collatzAccel` (Syracuse map), the meeting equivalence `pair_iff` (so the
  pair obligation at `w = 4u+1` is exactly the `u ↔ 18u+5` meeting; the
  current/meeting equivalence itself is a graph fact not restated), and the
  easy direction `collatz_imp_pairs_meet`, which needs
  `accel_reaches_one` (an odd `n` reaching 1 under `collatz` reaches 1 under
  `collatzAccel`; the only odd point on the orbit of 1 is 1). The converse,
  the content of R40, is **not** formalised: the repository proves it through
  the frozen framework (R25 normal form, R37 critical index, R40 W9
  elimination, R43 strict-rank induction). A direct minimal-counterexample
  attempt does not close it: for a component `D ≠ C₁` with minimum `m`,
  the pair relation only forces elements `≡ 23 (mod 36)` of `D` to be
  `≥ 18m+5`, and the Syracuse preimages `(2^a m − 1)/3` of `m` below
  `18m+5` (`a ≤ 5`) hit that class only when `m ≡ 35 (mod 54)`; so the
  converse is genuinely a framework theorem, not a one-line reformulation.
  `R1Converse` records the exact statement without asserting it.
