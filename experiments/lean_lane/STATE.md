## Statement-match notes

- Target 1: main's (1) in `invariant_colors.md` §1 is `h(2n)=h(n)` for
  `n>=1` and `h(3n+d)=h(n)` for odd `n>1`, with no identity at the absorber;
  §4/Appendix state "every periodic or eventually periodic d=1 invariant
  coloring is constant". The Lean theorem takes `h : ℕ → α`, `0 < M`,
  `∀ n, h (n+M) = h n`, `∀ n, h (2n) = h n`, `∀ n, Odd n → 1 < n → h (3n+1)
  = h n`, and concludes `∀ n, 0 < n → h n = h 1`. Hypotheses quantified
  over all of ℕ cost nothing: a colouring of the positive integers with
  period `M` extends to `0` by `h 0 := h M`, after which both all-ℕ
  hypotheses hold. So the Lean statement implies main's for every period.
  *Eventual* periodicity (Appendix, last paragraph) and the general
  `gcd(M,d)` classification are not yet formalised (queued under 1b). The
  control matches §5's `3x+5` example with the indicator of `5 ∣ n`.

- V004-iii: main's Theorem (V004 §1) is "every finite-valued binary-automatic
  `h` satisfying (1) is constant", using Cobham and the finite-kernel
  characterisation as external inputs. The Lean theorem
  `automatic_rigidity : CobhamStatement α → ∀ h, (∀ n, h(2n)=h n) → (∀ n,
  Odd n → 1 < n → h(3n+1)=h n) → KAutomatic 2 h → ∀ n, 0 < n → h n = h 1`
  makes those inputs visible in its own hypotheses: `KAutomatic k f` is
  finiteness of the kernel `{n ↦ f(k^e n + j) : j < k^e}` (the Eilenberg
  characterisation taken as definition, so no separate hypothesis is
  needed), and `CobhamStatement α` is Cobham's theorem in kernel form,
  quantified over **every** `f : ℕ → α` (never specialised to `h` or to its
  odd restriction). "Finite-valued" is not assumed separately:
  `finite_range_of_kernel2` proves that a finite 2-kernel forces a finite
  range, so `CobhamStatement α` is exactly the classical theorem over a
